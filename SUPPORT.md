## Getting help

Because this project is unsupported, please do not expect a response to
support requests. That said:

- For usage questions, start with the [`README.md`](README.md),
  especially the **Troubleshooting** section, and run
  `bash scripts/diag.sh`.
- You are welcome to open a GitHub issue, but issues are handled on a
  **best-effort, no-commitment** basis and may not receive a response.
- For suspected security vulnerabilities, see [`SECURITY.md`](SECURITY.md).
